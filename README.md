# Obras DF

Análise de projetos de infraestrutura com investimento federal previsto no Distrito Federal, com dados do Obrasgov.

[Acesse o relatório interativo](https://simulacro.cv/obras-df/). O notebook correspondente está em `relatorio_lablivre.ipynb`.

Fonte de dados: [Obrasgov](https://api.obrasgov.gestao.gov.br/obrasgov/api/swagger-ui/index.html#/Projeto%20De%20Investimento/buscarPorFiltro).

## Origem

O projeto começou como uma avaliação para o LabLivre. O [material de referência](https://docs.google.com/document/d/1WWBnAodJoDo40WZ6ysI5cGx90KFYAp7GTFLrWPjmMFE/edit?tab=t.0) e o notebook original documentam esse contexto.
